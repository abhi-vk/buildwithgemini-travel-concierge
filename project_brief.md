# My agent: travel-concierge
One-liner: A conversational agent that helps travelers discover destinations and plan personalized itineraries with a catalog of venues and activities.

Tool coverage:
- Memory: Remembers travel preferences, dietary restrictions, and past trips
- Tools: Weather lookup, timezone check, venue search, and itinerary builder
- Catalog/UI: Venue catalog and daily itinerary cards/tables (A2UI)
- Image gen: Destination postcards and venue visual previews
- Sandbox: Travel budget and expense calculation

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch: Code sandbox for budget calculations, Maps integration
